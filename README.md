# Car Racing Game

A car racing game developed using Python and Pygame.

## Features
- Car racing gameplay
- Keyboard controls
- Traffic simulation
- Collision detection
- Score tracking
- Game-over functionality

## Requirements
- Python 3.10 or later
- Pygame

## Installation

Install the dependencies:

    pip install -r requirements.txt

## Run the Game

    python car.py

## Controls

Use the keyboard controls configured in the game to steer, accelerate, and brake.
